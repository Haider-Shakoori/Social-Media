# Social-Media SaaS Delivery Plan

## Current status
- Repository: Haider-Shakoori/Social-Media
- Selected stack: relayWA-aligned NestJS + Next.js/React + PostgreSQL + Redis + pnpm
- Strategy: production official APIs / isolated experimental research / manual fallback
- VPS deployment: NOT authorized
- External developer apps, API billing, customer sessions: NOT configured

## Batches
01. Repo bootstrap, docs, health API, landing page, local infrastructure, CI.
02. Design system and complete public marketing site.
03. Authentication, authorization, multi-tenant schema, data isolation tests.
04. Workspaces, teams, brands and onboarding.
05. Plans, trials, quotas, manual billing.
06. Super-admin modules and website CMS.
07. Connector interface, provider capability registry and policy controls.
08. Eligible Meta provider integration and test account publication.
09. Cloudflare AI with strict quota cap and deterministic branded templates.
10. Editor, media library, campaign and post versioning.
11. Calendar and natural-language recurrence rules with safe validation.
12. Email and in-app approval flows, revocation and audit.
13. Optional relayWA WhatsApp approval and delivery fallback.
14. Persistent scheduled publication, idempotency and provider reconciliation.
15. Account Protection Center and incident kill switches.
16. Analytics and evidence-based recommendations.
17. Agency collaboration, client approval roles and reporting.
18. SEO, multilingual/RTL CMS, accessibility.
19. Security, load and release readiness.

## Batch acceptance definition
Working functionality and tests, types/builds passing, no leaked secrets, documented limitation when API rights missing, PR review, no production deployment without explicit authorization. Every phase is independent of the release of disallowed experimental connectors.
